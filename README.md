# MCP_ВыполнениеКода

Расширение-компонент к [MCP_Сервер](https://github.com/vladimir-kharin/1c_mcp): инструменты `execute_query` и `execute_code` для AI-клиентов (Cursor, Claude Desktop и др.) через HTTP-сервис MCP в базе 1С. Коробку `MCP_Сервер` это расширение **не меняет** — только регистрирует свой контейнер инструментов.

Public git: https://github.com/chubajs12/MCP_VypolnenieKoda

## Как это работает

**Model Context Protocol (MCP)** дает модели вызывать «инструменты» на вашем сервере. Коробка `MCP_Сервер` реализует протокол и HTTP-сервис; этот репозиторий добавляет инструменты выполнения кода и запросов в живой базе.

## Компоненты

1. **`src/`** — исходники расширения 1С (Designer XML).
2. **`build/MCP_ВыполнениеКода_v*.cfe`** — поставка для баз (собирается Full Load → UpdateDB → DumpCfg; в git не коммитится, см. `.gitignore`).
3. **Обработка `mcpexec_ИнструментВыполнениеКода`** — контейнер для `MCP_Сервер` (`ДобавитьИнструменты`, `ВыполнитьИнструмент`).

## Быстрый старт (база)

1. Установить неизмененный `MCP_Сервер` из [vladimir-kharin/1c_mcp](https://github.com/vladimir-kharin/1c_mcp).
2. Установить CFE этого репозитория **без безопасного режима** (см. раздел «Установка» ниже).
3. Опубликовать HTTP-сервис коробки на `127.0.0.1` с Basic-авторизацией.
4. Проверить инструменты: `execute_code`, `execute_query` (харнес: `scripts/mcp1c/mcp1c.py --list`).

На машине **chubajs12** (линия AI_1C): разработка в worktree `F:\AI_1C\projects\mcp-vypolnenie-koda_dev` (ветка `develop`); канонический clone — `F:\AI_1C\upstream\git\MCP_VypolnenieKoda` (`main`); после merge в `main` — `F:\AI_1C\harness\scripts\mcp\sync-mcp-vypolnenie-koda.ps1` копирует CFE в `harness\tools\mcp1c\`. Документация потока — `harness\docs\16_MCP_VypolnenieKoda.md`.

## Инструменты

Оба инструмента выполняются на сервере 1С под пользователем HTTP-сервиса. Ответ — JSON. Ссылки в `data` — объекты `{"_objectRef": true, "УникальныйИдентификатор", "ТипОбъекта", "Представление"}`, пустые ссылки — `null`. Даты — строка `ГГГГ-ММ-ДДTЧЧ:ММ:СС`. Ошибка уходит клиенту MCP с признаком `isError`: в тексте причина и строка кода.

### execute_query

Выполняет запрос на языке запросов 1С с правами текущего пользователя. Пакетный запрос возвращает результат последнего запроса пакета.

| Параметр | Тип | Обязательный | Смысл |
|----------|-----|--------------|--------|
| `query` | string | да | Текст запроса |
| `params` | object | нет | Параметры: `{"ИмяПараметра": значение}`. Значение — строка, число, булево, null, массив (для `В (&Список)`), дата строкой `ГГГГ-ММ-ДДTЧЧ:ММ:СС`, ссылка `{"_objectRef": true, "ТипОбъекта", "УникальныйИдентификатор"}` или предопределенное `{"_predefined": "Перечисление.Имя.Значение"}` |
| `limit` | number | нет | Сколько строк вернуть. По умолчанию 100. `0` — все строки |
| `include_schema` | boolean | нет | Добавить в ответ типы колонок (`schema`) |

Ответ: `success`, `data` (массив строк-объектов), `count` (строк в результате), `returned`, `truncated`, при `include_schema` — `schema.columns` (`name`, `types`).

### execute_code

Выполняет код на встроенном языке оператором `Выполнить`. Код — последовательность операторов: без `Процедура`/`Функция` и без `Возврат`. Значение для ответа присвоить переменной `Результат`.

| Параметр | Тип | Обязательный | Смысл |
|----------|-----|--------------|--------|
| `code` | string | да | Текст кода |

Ответ: `success`, `data` (значение `Результат`: примитивы, массивы, структуры, соответствия, таблицы и деревья значений, ссылки, `ДвоичныеДанные` строкой Base64), `messages` (тексты `Сообщить()`, если были).

## Права и безопасный режим

- Пользователь с правом «Администрирование» выполняет код без безопасного режима, если расширение установлено **без** флажка «Безопасный режим».
- Остальные пользователи — в безопасном режиме: без привилегированного режима, файлов, COM и внешних обработок.
- Если администратор видит в ошибке фразу про безопасный режим, флажок снят не был: «Функции для технического специалиста» → «Управление расширениями конфигурации», снять «Безопасный режим», начать новый сеанс.

Роль `mcpexec_ИнструментВыполнениеКода` назначается пользователю публикации вместе с ролью коробки `mcp_БазоваяРоль`.

## Установка

1. В базе уже стоит неизмененный `MCP_Сервер` (проверено с 1.9.1, [vladimir-kharin/1c_mcp](https://github.com/vladimir-kharin/1c_mcp)).
2. Загрузить `build/MCP_ВыполнениеКода_v1_0_1.cfe` расширением **без безопасного режима**. Загрузка нового расширения из Конфигуратора ставит безопасный режим, и тогда `execute_code` не работает с файлами и внешними обработками: флажок нужно снять.
3. Пользователь HTTP-сервиса — с правом «Администрирование», если нужны файлы и привилегированный режим.
4. Публиковать HTTP-сервис коробки только на `127.0.0.1`, с авторизацией. Пароль в этот репозиторий не класть.

Общие модули коробки, на которые опирается компонент: `mcp_Метаданные`, `mcp_ОбщегоНазначения`.
